# My Skill Set

This repository is a place to gather documents describing and consolidating the skills I posess.

## goal:
- Generate and maintain documents enumerating my experience and the skills I use.
- Generate documents that can be used to assemble a resume if necessary.
- Use the enumerated skills to formulate a plan for searching forr part-time work that does not conflict with Oracle.
- Provide content to update my linkedin profile.

## Conventions:
- Separate each work experience block into its own markdown file by location and date range.
- Generate markdown files for each type of technology used (enumerate the individual skills inside of each technology).
